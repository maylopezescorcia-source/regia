☁ Sincronización en la nube (multi-dispositivo)

No conectado. Los datos solo se guardan en este dispositivo.

Conecta el sistema a una base de datos gratuita de Firebase para que todos tus dispositivos vean la misma información en tiempo real.

¿Cómo consigo la configuración de Firebase?
  1. Entra a console.firebase.google.com y crea un proyecto gratuito.
  2. Ve a "Compilación" → "Firestore Database" → "Crear base de datos" → modo de prueba.
  3. Ve a Configuración del proyecto (⚙) → pestaña "General" → "Tus apps" → agrega una app Web (ícono </>).
  4. Copia el bloque const firebaseConfig = {...} que te muestra y pégalo arriba, tal cual (no hace falta editarlo).
  5. Ve a "Compilación" → "Authentication" → "Comenzar" → pestaña "Método de acceso" → habilita Correo electrónico/contraseña. Luego, en la pestaña "Usuarios", pulsa "Agregar usuario" y crea tu correo y una contraseña (ese será tu acceso de administrador). En "Configuración" de Authentication → "Acciones del usuario", desmarca "Habilitar creación (registro)" para que nadie más pueda crear usuarios.
  6. Abre en este sistema Tienda online → Seguridad, copia las reglas (ya llevan tu correo), pégalas en Firestore → pestaña "Reglas" (borrando lo anterior) y dale "Publicar".
  7. Inventa un "código de tienda" (una palabra o frase única) y úsalo en todos tus dispositivos.
