Todo el sistema se guarda solo en este navegador. Descarga una copia de seguridad periódicamente — si cambias de computador o se borra el navegador, es la única forma de recuperar tu información.

Restaurar reemplaza todos los datos actuales por los del archivo. Esta acción no se puede deshacer.

☁ Sincronización en la nube (multi-dispositivo)

No conectado. Los datos solo se guardan en este dispositivo.

Conecta el sistema a una base de datos gratuita de Firebase para que todos tus dispositivos vean la misma información en tiempo real.

¿Cómo consigo la configuración de Firebase?
  1. Entra a console.firebase.google.com y crea un proyecto gratuito.
  2. Ve a "Compilación" → "Firestore Database" → "Crear base de datos" → modo de prueba.
  3. Ve a Configuración del proyecto (⚙) → pestaña "General" → "Tus apps" → agrega una app Web (ícono </>).
  4. Copia el objeto firebaseConfig que te muestra y pégalo arriba, tal cual.
  5. En Firestore → pestaña "Reglas", pega la regla que Claude te indicó en el chat y publica.
  6. Inventa un "código de tienda" (una palabra o frase única) y úsalo en todos tus dispositivos.
